# 计算机体系结构 (Computer Architecture)

河南大学计算机科学与技术专业课程资料 - 计算机体系结构。

## 目录结构
- slides/: 课件与课件视频图集
- labs/: 实验 (包括实验指导与 C++ 实验项目源代码)
- exercises/: 习题 (包括雨课堂测试题)
- notes/: 笔记与复习资料
